# CRM-Vorlage für Google Sheets — Kostenlos

## Basis-Struktur

| Spalte | Inhalt | Beispiel |
|--------|--------|---------|
| ID | Automatisch | 001 |
| Name | Vollständiger Name | Max Mustermann |
| Unternehmen | Firmenname | Muster GmbH |
| E-Mail | Kontakt-Email | max@muster.de |
| Telefon | Direkte Nummer | +49 221 123456 |
| Quelle | Woher kam der Lead? | Website |
| Status | Aktueller Stand | Interessiert |
| Letzter Kontakt | Datum | 28.05.2026 |
| Nächste Aktion | Was tun? | Angebot schicken |
| Notizen | Freitext | Braucht Website bis Juli |

## Status-Werte (für Filterung)
- **Neu** — noch kein Kontakt
- **Kontaktiert** — erste Nachricht/Mail raus
- **Interessiert** — hat positiv reagiert
- **Angebot raus** — Angebot/Demo zugeschickt
- **Verhandlung** — preis- oder inhaltliche Abstimmung
- **Gewonnen** — Auftrag erhalten
- **Verloren** — kein Abschluss
- **Pause** — aktuell kein Bedarf, später wieder kontaktieren
